nnU-Net Module (Experimental Setup on CCUB Server)
Overview
This module describes the configuration, training, and integration of nnU-Net within the proposed comparative study framework. All experiments were conducted on the CCUB HPC cluster (University of Burgundy) due to the high computational requirements of nnU-Net training.
Environment
•	Python version: (your version)
•	nnU-Net version: (v2)
•	Hardware: CCUB HPC cluster (GPU-based nodes)
•	Framework: PyTorch-based nnU-Net implementation
Directory Structure
Train_Test_nnUNet/
│
├── nnUNet_raw/              # Raw dataset (medical images + masks)
├── nnUNet_preprocessed/     # Preprocessed data generated by nnUNet
├── nnUNet_results/          # Training outputs (models, logs, checkpoints)
Training Procedure
The nnU-Net training pipeline follows the standard 3-stage process:
1.	Dataset preparation in nnUNet_raw/
2.	Automatic preprocessing (resampling, normalization, patch extraction)
3.	Model training on CCUB GPU nodes
Training was executed using nnU-Net's default configuration pipeline.
Prediction Module
The prediction scripts are located in:
prediction_nnUNet/
They implement three experimental pipelines:
•	Pipeline A (baseline segmentation evaluation)
•	Pipeline B (classification-based evaluation)
•	Pipeline C (feature-based predictive analysis)
Each pipeline uses nnU-Net segmentation masks as input.
Example Execution
Each pipeline follows the same structure:
•	Load dataset and labels
•	Split train/test sets
•	Load nnU-Net predicted masks
•	Run experimental pipeline (A/B/C)
•	Compute performance metrics
•	Export results (CSV + summaries)
Important Configuration Variables
Defined in CONFIG:
•	LABELS_CSV
•	IMAGES_DIR
•	NNUNET_MASKS_DIR
•	OUTPUT_DIR
Outputs
Each pipeline generates:
•	Performance metrics (Dice, IoU, Precision, Recall)
•	CSV summaries per experiment
•	Comparative analysis across pipelines
•	Saved results per model
Notes
•	All nnU-Net experiments were executed independently from the other segmentation models.
•	Results are fully integrated into the global comparative study.
•	Due to computational cost, training was performed on HPC infrastructure (CCUB server).
Reproducibility
To reproduce results:
1.	Install nnU-Net environment
2.	Set environment variables for nnUNet_raw, nnUNet_preprocessed, nnUNet_results
3.	Run training pipeline on CCUB or equivalent GPU system
4.	Run prediction pipelines A/B/C.
