Prediction Module
This module evaluates the impact of segmentation quality on downstream clinical prediction tasks.
Purpose
The generated segmentations from different models are used as inputs for predictive pipelines in order to assess their influence on clinical outcome prediction.
Available Segmentation Models
•	U-Net
•	U-Net++
•	Attention U-Net
•	ResUNet
•	ResUNet++
•	Swin-Unet
•	TransUNet
•	UCTransNet
•	MedFormer
•	V-Net
•	nnU-Net
Main Components
prediction_scripts/
Contains the experimental prediction pipelines:
•	Pipeline A
•	Pipeline B
•	Pipeline C
Each pipeline can be executed independently using segmentation outputs generated by any of the evaluated segmentation models.
dataset.py
Provides data loading utilities for NIfTI medical images and segmentation masks.
models/
Contains prediction model definitions.
checkpoints/
Contains trained prediction model weights.
patients_response/
Contains patient-level response information used for prediction tasks.
Segmentations_Modeles/
Stores segmentation outputs generated by the different segmentation architectures.
Experimental Workflow
1.	Load patient images and labels.
2.	Load segmentation masks generated by a selected segmentation model.
3.	Split data into training and testing subsets.
4.	Execute the selected prediction pipeline.
5.	Compute predictive performance metrics.
6.	Export experimental summaries and reports.
Outputs
•	Prediction results
•	Performance summaries
•	Comparative analyses across segmentation models
•	CSV reports for each experimental pipeline
Reproducibility
All experiments can be reproduced by selecting a segmentation model and executing one of the provided pipelines (Pipeline A, Pipeline B, or Pipeline C).
